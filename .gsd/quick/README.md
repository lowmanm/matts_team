# Quick Tasks

Ad-hoc tasks that don't require full M→S→T scaffolding.

Each quick task lives in its own directory:
`.gsd/quick/[NNN]-[slug]/`
  PLAN.md     — goal, must-haves, steps
  SUMMARY.md  — what happened, files changed

Quick tasks are tracked here, not in milestones/.
They still get atomic git commits and summaries.

Start a quick task:
- In Copilot CLI: describe the task, the gsd-quick skill handles the rest
- Manually: create the directory and PLAN.md, then work it
